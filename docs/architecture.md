# BeamTorTool Architecture

## Overview
This project is organized into focused modules for commands, database access, generators, models, services, UI, and utilities.

## Suggested Structure
- src/commands: command classes for extension actions
- src/database: persistence and connection helpers
- src/generators: geometry or model generation logic
- src/models: domain objects
- src/services: orchestration layers
- src/ui: user interface components
- src/utils: shared helper methods
